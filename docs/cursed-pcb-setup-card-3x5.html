Cursed PCB ATtiny412 / setup
STOP

Set up Arduino
before uploading.

This is not a standard Arduino board. Use a USB-C data cable.

01

Install megaTinyCore

Arduino IDE → Preferences → Additional Boards Manager URLs:

http://drazzy.com/
package_drazzy.com_index.json

Then open Boards Manager, search megaTinyCore, and install the newest version by Spence Konde.

LED LIBRARY INCLUDED — tinyNeoPixel_Static; no separate download.
02

Connect + choose settings

Board
ATtiny412/402/212/202
without Optiboot
Clock
20 MHz internal
BOD voltage
4.2V (20 MHz or less)
Programmer
SerialUPDI – 230400 baud
03

Upload the example

Open LED_example.ino. Choose Sketch → Upload Using Programmer—not the regular Upload command.

External power: side VCC + GND only. Never feed the 5V pin or connect VCC power with USB-C. Regulator: 5 V / 100 mA total; ≥7 V input; 30 V absolute max. Higher VCC makes more heat; full-bright LEDs can exceed 100 mA.
